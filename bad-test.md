Welcome to My App!!!

## INTRODUCTION
This is my app, it is a really great app that helps you do lots of things!!! it lets you manage your tasks, track your projects, collaborate with your team and also sync everything across all of your devices!!! The app was designed from the ground up to be extremely powerful but also very simple to use, so even beginners can get started quickly without reading any documentation at all, although we do have documentation which you can find below in this readme if you need it.

## Overview
the installation process is pretty simple, you download the installer from our website, then you run it, then you follow the steps, then you're done. once installed you can log in with your account and start using the app immediately. if you have any problems you can contact our support team by email or visit our website for more help.

## Features

- task management with due dates and priorities
* project tracking with progress bars and milestones
- team collaboration with comments and file sharing
* sync across all your devices
- offline mode so you can work without internet
* custom themes and dark mode

## Quick Start

to get started you need to:

1. download the installer
1. run the installer
3. follow the setup wizard
4. log in
5. done

``` 
npm install my-app
```

or download from our website at https://www.myapp.example.com

## API

Here's the API (see also the docs which are located at docs/API.md and also docs/tutorial.md and also the changelog at CHANGELOG.md):

| Endpoint | Description |
| --- |
| /api/login | logs you in |
| /api/tasks | gets your tasks |
| /api/tasks (POST) | creates a new task |
